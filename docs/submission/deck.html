02 / The problemWORKFLOW HYPOTHESIS

A new data source should not require
open-ended payment authority.

For a small agent team, the useful unit to test is one task, one quote and one auditable purchase.

Developer

“Get the useful report.”

The agent may discover a paid resource while working. Its owner still needs a finite budget and expiry.

API provider

“Prove this purchase.”

A payment must match the merchant, amount and quoted resource before protected data is released.

When status is unclear

“Did it already pay?”

A timeout must preserve identity. A second signature or blind submission can create another charge.

Prepaid API keys can work well. We are testing whether bounded, per-request wallet purchasing improves this specific workflow. Demand and pricing are unvalidated.

Three-minute Q&A · presenter prompts

Did a model buy the current report? No. The saved proof is a configured headless agent-key authorization. The actual bounded model loop is still required.

Why Velo Gas? It actually sponsors, submits and observes the same Noir authorization. No checkout or webhook is implemented; organizer-specific acceptance is unconfirmed.

How does recovery avoid another charge? Persist identity and handoff before dispatch; observe the saved identity after uncertainty. Unknown stays unentitled. Application PostgreSQL race gates remain pending.

Why isn't the event enough? It lacks asset and agent. Match the successful envelope, invocation and byte-identical embedded event to Velo execution and the stored intent.

Is authorization merchant collection? Authorization credits merchant-pending escrow. Merchant claim is separate; it does not create another entitlement.

What is fictional? The proposed reports are fixture content. Chain authorization and claim are real Testnet evidence. There is no completed model app, production audit, commercial traction or x402 conformance claim.

What is missing? Real workspaces, app database/API/model/UI, release and deployment gates, public app/video/deck URLs, Discord and registration confirmation. Gas interpretation and late acceptance need organizer clarification.
