The implementation uses original React, CSS and SVG. No Magic UI, Watermelon UI, motion package or Impeccable executable was installed. These projects informed the quality bar and selected interaction patterns; none is represented as an installed library.

- [Magic UI Animated Beam](https://magicui.design/docs/components/animated-beam): inspected the actual page and [upstream implementation](https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/animated-beam.tsx). Its path/direction vocabulary informed user-triggered boundary highlighting. AegisPay does not run a looping beam or imply a historical payment is executing now. Source uses motion/react and ResizeObserver; the AegisPay implementation instead uses original responsive SVG geometry and finite CSS stroke animation. [MIT license](https://github.com/magicuidesign/magicui/blob/main/LICENSE.md).

[MIT license](https://github.com/WatermelonCorp/watermelon-platform/blob/main/LICENSE).
