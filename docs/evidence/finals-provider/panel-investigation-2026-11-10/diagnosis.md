## Immutable official source findings

All Velo links below use the already-indexed official commit `c63b3308ad69d2c5a919f94052571a38a2188121`. Tenets below are source analysis, not execution of provider code. The deployed frontend/backend versions at capture, handoff and investigation time are **unverified**. Matching UI text is insufficient to establish a version match.

1. **Specific unavailable-detail hypothesis: expired-record projection mismatch.** `expireGasUnsentExecutionAttempt` writes `expired`, zero fee, settled timestamp and cleared/advanced fences to the execution record and updates the audit. See [settlement.ts L565–578 and L634–660](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/packages/backend/convex/gas/settlement.ts#L565-L660). `getExecutionDetail` directly serializes any matching retained attempt, without an expired special case; see [queries.ts L424–443](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/packages/backend/convex/gas/queries.ts#L424-L443). That serializer accepts only `claimed`, `submission_unknown`, `submitted`, `succeeded`, `failed`, `cancelled`; `expired` throws `Invalid Gas execution projection`. See [projections.ts L259–313](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/packages/backend/convex/gas/projections.ts#L259-L313). Thus, **if this deployed query sees an expired attempt, it cannot return that attempt's DTO**. Authorization failure, ambiguous records or other malformed projection fields can also throw. No provider row or actual exception was read here.

2. **A detail-query error replaces the body, not the entire sheet.** The live body subscribes to the project/request query at [gas-activity.tsx L617–633](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/apps/web/features/projects/gas-activity.tsx#L617-L633). Its local error boundary renders the observed fallback and suppresses private error details; see [L157–188](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/apps/web/features/projects/gas-activity.tsx#L157-L188) and [L754–770](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/apps/web/features/projects/gas-activity.tsx#L754-L770). The body renders audit **before** execution loading/null/result branches, so the flash of audit text does not prove the execution query succeeded; see [L522–611](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/apps/web/features/projects/gas-activity.tsx#L522-L611). Audit disappearance merely produces `selectedAudit=null`; no effect resets selection on query/pagination/connection changes. See [L648–674](https://github.com/Velo-Ecosystem-Collection/Velo/blob/c63b3308ad69d2c5a919f94052571a38a2188121/apps/web/features/projects/gas-activity.tsx#L648-L674). A primitive dismissal/trigger event is one hypothesis; actual input/event cause is not captured. No claim about a particular browser or Radix defect is supported.
